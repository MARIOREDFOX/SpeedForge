# ⚡ Speedtest Studio

A beautiful, feature-rich internet speed test application with real-time hardware monitoring and a modern cyberpunk UI.

## ✨ Features

- **Real-time speed testing** - Download/upload speed measurement with live needle gauge animation
- **Live hardware monitoring** - CPU, RAM, and GPU usage during tests
- **Wave graph visualization** - Dynamic background graph showing speed fluctuations
- **Network statistics** - Ping, jitter, ISP info, and IP address display
- **System information** - Auto-detects CPU, RAM, and GPU specifications
- **Modern UI** - Dark theme with neon cyan (#00f5d4) accents
- **Instant updates** - Real-time network I/O monitoring (30ms sampling)
